# Resume Analysis (AI)

HireMe allows users to deeply analyze how well their resume matches a specific job description.

## Key Capabilities
- **Job Match Calculation:** The system calculates a definitive Match Score based on how closely the resume aligns with the job requirements. It evaluates Skills Match, Experience Match, Keyword Match, Project Relevance, Education, and ATS Readiness.
- **Skill Gap Analysis:** Highlights "Strong Matches" alongside "Missing Skills" that the candidate needs to acquire or highlight.
- **Bullet Point Optimizer:** Analyzes existing resume bullet points, identifies problems (e.g., lack of metrics), and suggests improved, impact-driven alternatives.
- **ATS Simulation:** Simulates how an Applicant Tracking System would parse the resume, listing passed and failed checks.
- **Interview Prep:** Anticipates likely interview topics and generates custom practice questions based on the gaps found in the resume.
- **Historical Tracking:** Users can view a complete history of their past resume analyses, allowing them to track improvements across iterations and different job roles.
