# Career Mentor Chat

The Career Mentor Chat is a persistent, AI-powered conversational interface designed to guide users through their career journey.

## Capabilities
- **Context Aware:** Remembers user preferences, skills, and past conversations to provide highly personalized advice.
- **Salary Negotiation:** Provides data-backed strategies for negotiating offers.
- **General Career Advice:** Helps with everything from deciding between two offers, navigating workplace conflicts, or deciding what skill to learn next.
- **Powered by Groq:** Utilizing ultra-low latency inference, the chat feels natural and instantaneous.
